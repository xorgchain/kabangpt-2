# **Welcome to KabanGPT-2!**

This is a Reborn-version of legacy KabanGPT. It has plenty of new things that highlights it from the first version (RELEASE SOON)

## **What it can do**
- Chat with lots of models through API function
- Generate Markdown-supportive answers: headings, lists, tables, formulas and code
- Run on almost every OS
- Easily change model when necessary

## **Desktop app**
This app uses Electron. The current build config is a Linux `.deb` package, but soon there will be `.exe` and `.dmg` versions

__*Quick start:*__
1. Install Node.js and npm
2. Run in terminal:
   ```bash
   git clone
   npm install
   npm run
   ```
3. Open Models page and add a provider

## **Providers**
Add a connection through Models 
page by choosing a provider and pasting API key. **Keys and providers are stored locally on your machine**. Supporting:
- OpenAI (ChatGPT)
- Anthropic (Claude)
- DeepSeek
- OpenRouter
- Groq
- Mistral
- Together AI (and more providers)
